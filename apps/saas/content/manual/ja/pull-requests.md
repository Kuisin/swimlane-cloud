# レビューとプルリクエスト

編集ブランチに変更をプッシュしたら、**レビューを依頼**でそのブランチから `preview` へのプルリクエストが作成されます。これは GitHub や GitLab 上の実際のプルリクエストであり、Swimlane Cloud だけの独自の概念ではありません。

## レビュアーが目にするもの

**プルリクエスト**タブには、プロジェクトのすべての未処理のリクエストが一覧表示されます。1 つを開くと、変更されたすべての図の差分が並んで表示されます —— DSL のテキスト差分ではなく、変更の様子を実際に描いた画像として表示されるため、レビュアーは DSL を読まなくても、何が移動し、何が追加され、何が削除されたのかを正確に確認できます。

## 承認とマージ

編集者以上の権限を持つ人は誰でもコメントや承認ができます。承認されたら、実際に `preview` を更新するのはマージです。前述のとおり、`preview` はマージされたプルリクエストを通じてのみ変わります。マージ後、あなたの編集ブランチはそこで完了し、削除できます。次に**編集を開始**をクリックすると、新しいブランチが作成されます。

## マージせずにクローズする

変更が結局不要だとわかった場合は、マージせずにプルリクエストをクローズすれば、`preview` はそのまま変更されず、編集ブランチのロックも解除されて再度作業できるようになります。
