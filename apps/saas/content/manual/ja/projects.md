# プロジェクト

Swimlane Cloud における**プロジェクト**とは、GitHub（または GitLab）リポジトリそのものです。何かをコピーして「プロジェクトを作成する」という別の手順はなく、Swimlane Cloud はあなた自身のアカウント権限でリポジトリを直接読み書きします。

## リポジトリがプロジェクトになる仕組み

リポジトリに **`swimlane`** というトピックが付くと、ダッシュボードに表示されるようになります。方法は 2 つあります。

- **新規作成** — Swimlane Cloud があなたのために非公開リポジトリを作成し、サンプル図と `.swimlane.json` 設定ファイルを配置し、トピックを自動的に付けます。
- **既存を登録** — すでに所有している、または push 権限のあるリポジトリを選びます。まだ無ければ `.swimlane.json` を追加してトピックを付けるだけで、それ以外は何も変更しません。

`.swimlane.json` は図を格納するフォルダ名を指定するだけのファイルです（デフォルトは `diagrams`）。リポジトリの他の部分は自由に使えます。

## ロールは Swimlane Cloud ではなく GitHub から来る

管理すべき別の権限システムはありません。あなたのロールは、リクエストごとにリポジトリへの GitHub 権限から読み取られます。

| GitHub の権限    | Swimlane Cloud のロール | できること                       |
| ---------------- | ----------------------- | -------------------------------- |
| Admin            | **オーナー**            | テンプレートや公開を含むすべて   |
| Push             | **編集者**              | 図の編集・プッシュ・レビュー依頼 |
| Pull（読み取り） | **閲覧者**              | 図の閲覧・履歴の確認             |

GitHub 上でアクセス権を変更すれば、ここにも即座に反映されます。同期する手間はありません。

## Swimlane Cloud だけに存在するものはない

図そのものはリポジトリ内のファイルです。仮に Swimlane Cloud の利用を明日やめても、すべての図はプレーンテキストとしてそのまま残ります。Swimlane Cloud 自身のデータベースに保存されるものは小さく、失われても困らないものだけです。プッシュ前の自動保存ドラフト、表示を速くするためのバージョンスナップショット、再利用テンプレート、操作履歴 —— どれも図の正本ではありません。
