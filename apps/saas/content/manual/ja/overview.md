# Swimlane Cloud へようこそ

Swimlane Cloud は、役割・ステップ・分岐・並行処理を含む**業務フロー図**（スイムレーン図）を、**あなた自身の GitHub または GitLab リポジトリ**内のプレーンテキストファイルとして描き、管理するためのサービスです。図だけを別に管理するデータベースはありません。リポジトリそのものが図であり、ここで行うすべての操作は、裏側では通常のコミット・ブランチ・プルリクエストにすぎません。

## 最短の流れ

1. **ダッシュボード**からリポジトリを開きます。`swimlane` トピックが付いたリポジトリは自動的に表示されます。
2. **編集を開始**をクリックします。あなた専用の編集ブランチが作成され、`main` や `preview` を直接編集することはありません。
3. **ビジュアルモード**（構文を覚える必要なし）または**テキストモード**（構文を直接扱いたい人向けの完全な DSL）で図を編集します。
4. **プッシュ**で変更を 1 つのコミットにまとめます。**レビューを依頼**で `preview` へのプルリクエストを作成します。
5. 承認・マージされたら、**公開**でバージョンにタグを付け、`main` に反映します。

以下の各セクションは、この流れの各ステップを詳しく説明します。
