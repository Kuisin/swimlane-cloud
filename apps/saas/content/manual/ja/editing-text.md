# 図の編集：テキストモード

テキストモードは、図が実際に書かれている元の言語です。どのように作られた図であっても、実体はこのテキストにすぎません。テキストモードに切り替えてもビジュアルモードで行った内容が失われることはなく、逆に戻してもここで書いた内容が失われることもありません。

## 基本の形

```
@kai-swimlane

/title/
承認フロー;

/role/
<sales>
label: 営業;

/line/
[sales: 受注する]

if (承認する？)
case (はい) #green
  [sales: 出荷する]
case () #red
  [sales: 却下を連絡する]
end-if

@end
```

- `/title/`、`/role/`、`/block/`、`/prop/` で図のタイトル、関わる人、共有の見た目のスタイルを設定します。
- `/line/` がフローそのものです。`[role: text]` 形式のステップに加え、`if`・`fork`・`section` などいくつかのフロー用キーワードがあります。

閉じ記号は `end-if`・`end-fork`・`end-section`・`end-branch`、追加のケースは `case (…)` と書きます。残り全部を受け止めるケースは空の `case ()` で、`else` という書き方はありません。古い表記の `endif`・`endfork`・`elseif` は読み込まれません。エディタが該当行と、代わりに使う表記を報告します。

## 完全な構文リファレンスはワンクリック

編集中に **?** ボタン（またはそこに表示されるキーボードショートカット）を押すと、すべてのキーワード・プロパティ・例を網羅した検索可能なリファレンスが開きます。以下の「文法の全体」は同じ内容を文章にしたものです。

## フォーマット

**フォーマット**ボタンは、意味を変えずにファイルを一貫したインデントの正規形式に書き直します。ファイルにエラーがある間は無効になっているので、今見ているものが有効かどうかが常にわかります。

## 1 つのファイルに複数言語

`@lang`（例：`@lang ja, en;`）で図に複数のコンテンツ言語を宣言できます。宣言後は、翻訳可能なテキストをインラインで並べて書く（`テキスト | Text`）か、別の行にタグ付きで書く（`text.en: Text;`）ことができます。詳しい規則は下の「文法の全体」を参照してください。

## 共有部品の読み込み

`@use ./shared-roles.txt;` で、別のファイルのロール・ブロック・スタイル・サイドノートの定義をこのファイルに取り込めます。ロールの集合や社内スタイルを 1 か所だけで定義し、複数の図で再利用できます。手で `@use` を書く代わりに、これを管理してくれる仕組みについては[再利用テンプレート](?section=templates)を参照してください。

## 文法の全体

この文法が受け付けるものをセクションごとにすべて挙げます。プロパティ行は必ず `;` で終わります。空白（インデントを含む）は区切り以外の意味を持たず、パーサーは無視します。`//` で始まる行はコメントです。

### ファイル

| 構文               | 意味                                                                                                                                                   | 例                |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------- |
| ヘッダー           | 図の開始。書き方は `@kai-swimlane` の 1 つだけで、バージョンはありません。古いバージョン付きのヘッダーはエラーになり、**DSL を更新**の実行を促されます | `@kai-swimlane`   |
| `@end`             | 図の終わり。これより後は無視される                                                                                                                     | `@end`            |
| セクションマーカー | セクションの開始。`/meta/`・`/title/`・/page/・`/option/`・`/role/`・`/block/`・`/prop/`・`/line/`・`/i18n/` の 9 つで、順序は自由                     | `/line/`          |
| コメント           | 行全体のメモ。`/* … */` でも書ける。保存時に残るのは `/line/` の中のコメントだけ                                                                       | `// 法務確認済み` |

### `/meta/`

図に関する自由記述のメタデータで、描画には使われません。アプリが認識するキーは `owner`・`status`（`draft`・`review`・`approved`・`deprecated`）・`tags`（カンマ区切りの一覧）・`updated`（`YYYY-MM-DD`）で、それ以外のキーもファイルには残りますが読み取られません。

```
@kai-swimlane

/meta/
owner: sales-ops;
status: draft;
tags: order, approval;

/title/
承認フロー;

/line/
[sales: 受注する]

@end
```

### `/title/` と `/page/`

| 構文                        | 意味                                                                                    | 例                               |
| --------------------------- | --------------------------------------------------------------------------------------- | -------------------------------- |
| タイトル                    | 自由なテキスト。`;` は不要。複数行は空白でつながる                                      | `承認フロー`                     |
| `description:`              | タイトルの下に出る説明                                                                  | `description: 受注から出荷まで;` |
| `header-left/center/right:` | ページヘッダーの 3 枠                                                                   | `header-center: 第 3 版;`        |
| `footer-left/center/right:` | ページフッターの 3 枠                                                                   | `footer-right: 2026-09-06;`      |
| 長い値                      | `/page/` とステップのテキスト系プロパティは、3 つのバッククォートで囲んで複数行に書ける | 「ステップのプロパティ」を参照   |

### `/option/`

オン・オフの切り替えといくつかの設定値、4 つの欄見出しです。書かなかったものは既定値のままです。

| キー                                    | 値                                                                  | 既定値                     |
| --------------------------------------- | ------------------------------------------------------------------- | -------------------------- |
| `show-left-gutter`, `show-right-gutter` | `true` / `false`                                                    | `true`                     |
| `show-header`, `show-footer`            | `true` / `false`                                                    | `true`                     |
| `show-description`                      | `true` / `false`                                                    | `true`                     |
| `show-step-block-captions`              | `true` / `false`                                                    | `true`                     |
| `merge-at-previous-block`               | `true` / `false`                                                    | `true`                     |
| `show-notes`, `auto-define`             | `true` / `false`                                                    | `true`                     |
| `branch-color-arrows`                   | `true` / `false`                                                    | `false`                    |
| `i18n-strict`, `i18n-uniform-layout`    | `true` / `false` —— 「1 つのファイルに複数言語」を参照              | `false`                    |
| `show-gateway-icons`                    | `true` / `false` —— `if` のひし形と `fork` のバーの中に描くアイコン | `true`                     |
| `block-margin`                          | `0`〜`80` の整数（ピクセル）—— ステップの箱のまわりの余白           | `0`                        |
| `block-text`                            | `truncate` または `wrap` —— 箱に入りきらないテキストの扱い          | `truncate`                 |
| `i18n-storage`                          | `as-written`・`catalog`・`inline` —— 翻訳した値をどこに書くか       | `as-written`               |
| `lane-order`                            | ロール id のカンマ区切り一覧 —— レーンの描画順                      | 定義順                     |
| `left-title`, `left-subtitle`           | テキスト —— 左の欄の 2 つの見出し                                   | `Procedure`・`Description` |
| `right-title`, `right-subtitle`         | テキスト —— 右の欄の 2 つの見出し                                   | `Remark`・空               |

オン・オフには `yes`/`on`/`1` と `no`/`off`/`0` も使えます。4 つの見出しは `/page/` にも書けますが、両方にある場合は `/option/` が勝ちます。

### `/role/`・`/block/`・`/prop/`

定義はどれも `<id>` を 1 行で書き、その下にプロパティを並べる形です。id は大文字小文字を区別し、`/line/` から参照されます。

| セクション | 定義するもの                 | キー                                                                                                                     |
| ---------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `/role/`   | スイムレーン 1 本            | `label`・`text-color`・`background-color`・`icon`                                                                        |
| `/block/`  | 再利用するステップのスタイル | `label`・`background-color`・`text-color`・`border-color`・`shape`・`icon`                                               |
| `/prop/`   | 脇に付く付箋                 | `label`・`side`（`left`/`right`）・`background-color`・`border-color`・`text-color`・`title`（別名 `hint`）・`max-chars` |

`shape` は `rounded`・`rect`・`note`・`hex`・`subroutine`・`ellipse`・`cloud` のいずれかです。`icon` の値が `#` で始まるときはアイコン名（`icon: #user;`）、`@` で始まるときは `@use` で取り込んだ画像（`icon: @kai-mark;`）、それ以外は絵文字や文字がそのまま表示されます。ここにないキーもファイルには残り、描画されないだけです。`/line/` から参照されたのに定義がないロール・ブロック・付箋は自動的に作られます。

```
@kai-swimlane

/title/
定義の例;

/role/
<sales>
label: 営業;
text-color: #1f2937;
background-color: #e0f2fe;
icon: #user;

/block/
<gateway>
label: 判断;
background-color: #ffe0b3;
border-color: #f59e0b;
shape: hex;

/prop/
<RQ>
label: 申請書;
side: right;
max-chars: 12;

/line/
[sales: 見積を作成する] <gateway> +RQ

@end
```

### ステップ

| 構文         | 意味                                                                       | 例                        |
| ------------ | -------------------------------------------------------------------------- | ------------------------- |
| ステップ     | `sales` レーンの箱 1 つ                                                    | `[sales: 見積を作成する]` |
| スタイル参照 | `/block/` のスタイルを適用する。行の末尾にのみ書ける                       | `[sales: 見積] <gateway>` |
| スペーサー   | 何も入らない 1 行。レーンもテキストも id もなく、番号も振られない          | `[]`                      |
| 空のステップ | レーンはあるがテキストがないステップ。空の箱として描かれ**番号は振られる** | `[sales:]`                |

ロール id に使えるのは英数字・`_`・`-` です。テキストにはコロンを含め何でも書けます。

### ステップの接尾辞

`[role: text]` の直後に、順序を問わず直接書きます。

| 接尾辞    | 意味                                                                                                          | 例                  |
| --------- | ------------------------------------------------------------------------------------------------------------- | ------------------- |
| `<block>` | `/block/` のスタイルを適用する                                                                                | `<gateway>`         |
| `+prop`   | `/prop/` の付箋を付ける。付箋ごとに繰り返せる                                                                 | `+RQ +LG`           |
| 矢印      | このステップから出る線の種類：`~>` 破線、`..>` 点線、`-.>` 一点鎖線、`-->` 長破線。実線が既定で記号は書かない | `~>`                |
| `=> path` | 別のフローを開く。このファイルからの相対パス、または `/` で図のルートから                                     | `=> ../ops/pick.md` |

### ステップのプロパティ

対象のステップの下に 1 行ずつ書きます。

| 構文           | 意味                                               | 例                               |
| -------------- | -------------------------------------------------- | -------------------------------- |
| `label:`       | 左の欄に出る見出し（箱の中のテキストは変わらない） | `label: 起案;`                   |
| `desc:`        | 説明欄                                             | `desc: 顧客要件を確認する;`      |
| `remark:`      | 備考欄                                             | `remark: 100 万円超は本部承認;`  |
| `remark-desc:` | `remark:` に段落を 1 つ追加する。繰り返せる        | `remark-desc: 上長が承認する。;` |
| `id:`          | ジャンプの行き先として指せるように名前を付ける     | `id: closed;`                    |
| `skip;`        | このステップを採番から外す                         | `skip;`                          |
| `level:`       | 採番上の深さ。`1`〜`9`                             | `level: 2;`                      |

番号はレーンを持ち `skip;` の付いていないステップに順に振られます。`level:` はそれを入れ子にします。レベル 1 は 1, 2, 3 と数え、2 の後のレベル 2 は 2-1、次が 2-2、その後のレベル 3 は 2-2-1 になります。

長い `desc:` や `remark:` は複数行で書けます。

````
@kai-swimlane

/title/
長い値;

/line/
[sales: 見積を作成する]
desc: ```
顧客要件を確認し、
見積を作成する。
```;

@end
````

### フロー

| 構文             | 意味                                                                                                                          | 例                     |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `if (question)`  | 分岐の開始。`#color` は任意でひし形の色になる                                                                                 | `if (承認する？)`      |
| `case (label)`   | 1 つのケース。`#color` は任意。空の `case ()` が残り全部を受け止める——`else` という書き方はなく、空のケースは何個あってもよい | `case (はい) #green`   |
| `end-if`         | 分岐を閉じる                                                                                                                  | `end-if`               |
| `fork`           | 並行する経路の開始。自身の任意ラベルが経路 1 の名前になる                                                                     | `fork #purple`         |
| `and (label)`    | 次の並行経路の開始。ラベルは任意                                                                                              | `and (出荷)`           |
| `end-fork`       | 並行経路を合流させる                                                                                                          | `end-fork`             |
| `section (名前)` | ステップをラベル付きの枠で囲む。フロー自体は変わらない                                                                        | `section (見積) #gray` |
| `end-section`    | 枠を閉じる                                                                                                                    | `end-section`          |
| `branch (名前)`  | 脇道。先頭はつながらず、末尾が閉じた後の流れに合流する                                                                        | `branch (監査) #blue`  |
| `end-branch`     | 脇道を閉じる                                                                                                                  | `end-branch`           |
| `phase (名前)`   | 左の欄に名前が出る横方向の帯。中に完全な `if`/`fork`/`section`/`branch` を入れられる                                          | `phase (見積) #gray`   |
| `end-phase`      | 帯を閉じる                                                                                                                    | `end-phase`            |

色名は `blue`・`green`・`red`・`orange`・`purple`・`gray`・`black`・`pink`・`teal`・`yellow` の 10 種類です。

### ジャンプ

着地点という行はもうありません。ジャンプの行き先は、すでにそこにあるノードの名前です。ステップは `id:` の行で、分岐・並行経路・枠・脇道・帯は開始行に書く `@id` で名前を付けます。

| 構文         | 意味                                                            | 例               |
| ------------ | --------------------------------------------------------------- | ---------------- |
| `[goto: id]` | ケースの中から、`id` という名前のステップ・分岐・並行経路へ進む | `[goto: closed]` |
| `loop`       | ケースの中から、直近の `if` の質問へ戻る                        | `loop`           |
| `loop @id`   | `@id` という名前の分岐・並行経路へ戻る                          | `loop @quote`    |

`[goto: id]` はステップに似た見た目ですがステップではありません。`goto` は予約語なので、`goto` という名前のロールは作れません。行き先は必ず必要で、行き先のない `goto` はありません。

```
@kai-swimlane

/title/
ジャンプ;

/role/
<sales>
label: 営業;

/line/
if (承認する？)
case (はい)
  [sales: 出荷する]
  [goto: closed]

case (修正が必要)
  [sales: 見積を修正する]
  loop

case ()
  [sales: 却下を連絡する]
  [goto: closed]
end-if

[sales: 案件を終了する]
  id: closed;

@end
```

### 読み込まれなくなった表記

以下はそれぞれエラーになり、代わりの表記が示されます。`endif` → `end-if`、`endfork` → `end-fork`、`elseif` → `else-if`、`section-start (n)` → `section (n)`、`start-point` → `section`、`end-point` → `end-section`。

### 古いファイルの移行

この文法より前に書かれたファイル——`@kai-swimlane-v2`（あるいは `2`）のヘッダー、`if (…) is (…) than` / `else-if … than` / `else`、`[loop]`、ステップの `props:` / `arrow:` / `link:` のプロパティ行など——はここでは読み込まれません。読み込むしくみは 1 つだけで、互換レイヤーはないため、最初に出会った古い構文でエラーになります。プロジェクトの編集画面にある**DSL を更新**アクションは、あるブランチのすべての図を 1 コミットでまとめて書き換えます。ヘッダーは `@kai-swimlane` に、`if (q) is (a) than` は `if (q)` と `case (a)` に、`else-if (b) than` は `case (b)` に、`else` は空の `case ()` に、`[loop]` は `loop` に、`merge: id;` と `[merge: id]` は `[goto: id]` に、ステップの `props:` / `arrow:` / `link:` 行は接尾辞の `+prop`・矢印記号・`=> path` に変わります。ステップの `id:` の行は現在の文法そのままなので手を加えません。ファイルのそれ以外は変更されません。

**ひとつだけ、自動で置き換えられない書き方があります——行き先のないジャンプです。** ケースの中の裸の `merge;` と `[merge]`、およびフロー中の `[merge]` / `[merge: name]` の着地点は、どこを指しているのかが書かれていません。着地点という行自体がなくなったため、置き換え先もありません。**DSL を更新**はこれらの行に手を触れず、そのあとファイルはその行ごとにエラーを報告します。手作業で直してください——着地させたいステップに `id:` の行を付け、ジャンプを `[goto: id]` と書き換えます。

## ビジュアルモードでできること・できないこと

テキストモードでは上記のすべてを書けます。ビジュアルモードはその大部分をカバーし、編集できないものも、下の表に別途書いていない限り、ビジュアルモードで保存しても**そのまま保持**されます。

| 機能                                                                                                                                                                    | ビジュアルモード                       | 補足                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| タイトル、ページの説明、ヘッダー・フッターの各枠                                                                                                                        | 編集できる                             | **設定**の中。対応する `show-…` がオフの間はその枠自体が表示されない                                                  |
| 欄見出し                                                                                                                                                                | 編集できる                             | 左の 2 つは左の欄がオフの間、右の 2 つは右の欄がオフの間は表示されない                                                |
| `show-left-gutter`・`show-right-gutter`・`show-header`・`show-footer`・`show-description`・`show-step-block-captions`・`merge-at-previous-block`・`branch-color-arrows` | 編集できる                             | **設定**のチェックボックス                                                                                            |
| `show-gateway-icons`・`block-margin`・`block-text`・`show-notes`・`auto-define`・`i18n-strict`・`i18n-uniform-layout`・`i18n-storage`・`lane-order`                     | **テキストモードのみ**                 | 対応する操作がまだない。値は保持される                                                                                |
| ロール・ブロック・付箋の定義                                                                                                                                            | 編集できる                             | すべてのプロパティと、追加・削除                                                                                      |
| 定義の `<id>` の変更                                                                                                                                                    | **テキストモードのみ**                 | id は表示されるが編集できない                                                                                         |
| レーンの並び順                                                                                                                                                          | **テキストモードのみ**                 | 定義した順に並ぶ。`/option/ lane-order:` があればそれに従う                                                           |
| ステップの追加・編集・削除・並べ替え                                                                                                                                    | 編集できる                             | 上下移動と**移動先**は同じ分岐の中に限られる。ドラッグでは分岐をまたげるが、ファイルが壊れる移動は拒否される          |
| ステップの `<block>`                                                                                                                                                    | 編集できる                             | 見た目で選べる                                                                                                        |
| `label:`・`desc:`・`remark:`・`+prop`・矢印                                                                                                                             | 編集できる                             | **詳細オプション**の中                                                                                                |
| ステップの `id:`                                                                                                                                                        | **手で書くことはない**                 | ジャンプがそのステップを指したとき・指さなくなったときに自動で付き、外れる。id そのものを表示・入力する欄はない       |
| `level:`                                                                                                                                                                | 対応                                   | 採番の階層 1〜9                                                                                                       |
| `=> path`                                                                                                                                                               | 対応                                   | 「別のフローへリンク」でファイルを選ぶ。ブロックの ↗ をプレビューでクリックすると開く                                 |
| `skip;`                                                                                                                                                                 | **テキストモードのみ**                 | 保存しても保持される                                                                                                  |
| `remark-desc:`                                                                                                                                                          | **テキストモードのみ**、かつ書き換わる | 保存すると `remark:` 1 つにまとめられる。文章は残るが 2 行の形は残らない                                              |
| スペーサー `[]`                                                                                                                                                         | 表示・削除のみ                         | ビジュアルモードでは作成も編集もできない                                                                              |
| `if`・`case`、条件、ケースのラベル、色                                                                                                                                  | 編集できる                             | 色は色名ではなく見本から選ぶ                                                                                          |
| `fork`・`and`                                                                                                                                                           | 挿入と色の変更                         | 文法上は並行経路にラベルを付けられるが、ビジュアルモードにはまだその入力欄がない——テキストモードで付ける              |
| `section`・`branch`・`phase`、名前と色                                                                                                                                  | 編集できる                             | 一方から他方へ変換する操作はない。`phase` はグループとして表示されるが、新規作成できるのは `section` と `branch` だけ |
| `loop`・`loop @id`                                                                                                                                                      | 挿入のみ                               | 設定項目はない                                                                                                        |
| `[goto: id]`                                                                                                                                                            | 編集できる                             | 行き先は id を入力するのではなく、ステップを選ぶドロップダウン                                                        |
| コメント                                                                                                                                                                | **テキストモードのみ**、かつ壊れやすい | 保存では保持されるが、ビジュアルモードのどこにも表示されず、ステップを削除するとそれに付いたコメントも消える          |
| `/option/` の未知のキー                                                                                                                                                 | **消える**                             | エラーとして報告され、ビジュアルモードで保存すると行ごと削除される                                                    |
| 言語ごとの値（`@lang`、インラインの `\|` 区切り、`field.lang:` 行）                                                                                                     | **テキストモードのみ**                 | ビジュアルモードで編集すると先頭の言語だけが変わり、他の言語はそのまま残る                                            |
| `@use`・`/meta/`                                                                                                                                                        | **テキストモードのみ**                 | 保存しても保持される                                                                                                  |

ファイルにエラーがあるときロックされるのは、そのエラーに対応する行だけで、ほかは編集できます。`/option/`・`/role/`・`/block/`・`/prop/`・`/page/`・`/title/` のエラーはどの行にも対応しないためどこもロックしません——そうしたエラーはテキストモードで直してください。
