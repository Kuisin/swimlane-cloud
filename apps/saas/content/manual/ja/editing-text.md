# 図の編集：テキストモード

テキストモードは、図が実際に書かれている元の言語です。どのように作られた図であっても、実体はこのテキストにすぎません。テキストモードに切り替えてもビジュアルモードで行った内容が失われることはなく、逆に戻してもここで書いた内容が失われることもありません。

## 基本の形

```
@kai-swimlane

/title/
承認フロー

/role/
<sales>
label: 営業;

/line/
[sales: 受注する]

if (承認する？) is (はい) than
[sales: 出荷する]
else
[sales: 却下を連絡する]
end-if

@end
```

- `/title/`、`/role/`、`/block/`、`/prop/` で図のタイトル、関わる人、共有の見た目のスタイルを設定します。
- `/line/` がフローそのものです。`[role: text]` 形式のステップに加え、`if`・`fork`・`section` などいくつかのフロー用キーワードがあります。

エディタが書き出すのは `end-if`・`end-fork`・`else-if` です。既存のファイルで使われている古い表記
`endif`・`endfork`・`elseif` も引き続き問題なく読み込め、動作します——新しい表記に変わるのは
フォーマットまたは保存し直したファイルだけです。

## 完全な構文リファレンスはワンクリック

編集中に **?** ボタン（またはそこに表示されるキーボードショートカット）を押すと、すべてのキーワード・プロパティ・例を網羅した検索可能なリファレンスが開きます。以下の「文法の全体」は同じ内容を文章にしたものです。

## フォーマット

**フォーマット**ボタンは、意味を変えずにファイルを一貫したインデントの正規形式に書き直します。ファイルにエラーがある間は無効になっているので、今見ているものが有効かどうかが常にわかります。

## 1 つのファイルに複数言語

`@lang`（例：`@lang ja, en;`）で図に複数のコンテンツ言語を宣言できます。宣言後は、翻訳可能なテキストをインラインで並べて書く（`テキスト | Text`）か、別の行にタグ付きで書く（`text.en: Text;`）ことができます。これはバージョン 2 の機能です——後述の「言語には 2 つのバージョンがある」を参照してください。

## 共有部品の読み込み

`@use ./shared-roles.txt;` で、別のファイルのロール・ブロック・スタイル・サイドノートの定義をこのファイルに取り込めます。ロールの集合や社内スタイルを 1 か所だけで定義し、複数の図で再利用できます。これもバージョン 2 の機能です。手で `@use` を書く代わりに、これを管理してくれる仕組みについては[再利用テンプレート](?section=templates)を参照してください。

## 言語には 2 つのバージョンがある

いちばん最初の行で、どちらの文法で読むかが決まります。

- `@kai-swimlane` —— **バージョン 1**。新規作成の図とすべてのスターターテンプレートはこれで書かれており、以下の「文法の全体」はこのバージョンの説明です。
- `@kai-swimlane-v2` —— **バージョン 2**。セクションの構成も `[role: text]` のステップも同じですが、空白の位置が意味を持たなくなり、`if` から `is (…) than` が消え、`else` は空の `case ()` になり、`@lang`・`@use`・`phase`・ノート・リンクが使えるようになります。変換するか、自分で `-v2` のヘッダーを書いたときにだけバージョン 2 になります。

どちらも完全にサポートされており、既存の図を移行しなければならないということはありません。

## 文法の全体

バージョン 1 が受け付けるものをセクションごとにすべて挙げます。プロパティ行は必ず `;` で終わります。インデントは飾りで、パーサーは無視します。`//` で始まる行はコメントです。

### ファイル

| 構文               | 意味                                                                                                             | 例                |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- | ----------------- |
| ヘッダー           | 図の開始。どちらの文法かもここで決まる                                                                           | `@kai-swimlane`   |
| `@end`             | 図の終わり。これより後は無視される                                                                               | `@end`            |
| セクションマーカー | セクションの開始。`/page/`・`/title/`・`/option/`・`/role/`・`/block/`・`/prop/`・`/line/` の 7 つで、順序は自由 | `/line/`          |
| コメント           | 行全体のメモ。`***` でも書ける。保存時に残るのは `/line/` の中のコメントだけ                                     | `// 法務確認済み` |

### `/title/` と `/page/`

| 構文                        | 意味                                                                                    | 例                               |
| --------------------------- | --------------------------------------------------------------------------------------- | -------------------------------- |
| タイトル                    | 自由なテキスト。`;` は不要。複数行は空白でつながる                                      | `承認フロー`                     |
| `description:`              | タイトルの下に出る説明                                                                  | `description: 受注から出荷まで;` |
| `header-left/center/right:` | ページヘッダーの 3 枠                                                                   | `header-center: 第 3 版;`        |
| `footer-left/center/right:` | ページフッターの 3 枠                                                                   | `footer-right: 2026-09-06;`      |
| 長い値                      | `/page/` とステップのテキスト系プロパティは、3 つのバッククォートで囲んで複数行に書ける | 「ステップのプロパティ」を参照   |

### `/option/`

9 つのオン・オフ、2 つの設定値、4 つの欄見出しです。書かなかったものは既定値のままです。

| キー                                    | 値                                                                  | 既定値                     |
| --------------------------------------- | ------------------------------------------------------------------- | -------------------------- |
| `show-left-gutter`, `show-right-gutter` | `true` / `false`                                                    | `true`                     |
| `show-header`, `show-footer`            | `true` / `false`                                                    | `true`                     |
| `show-description`                      | `true` / `false`                                                    | `true`                     |
| `show-step-block-captions`              | `true` / `false`                                                    | `true`                     |
| `merge-at-previous-block`               | `true` / `false`                                                    | `true`                     |
| `branch-color-arrows`                   | `true` / `false`                                                    | `false`                    |
| `show-gateway-icons`                    | `true` / `false` —— `if` のひし形と `fork` のバーの中に描くアイコン | `true`                     |
| `block-margin`                          | `0`〜`80` の整数（ピクセル）—— ステップの箱のまわりの余白           | `0`                        |
| `block-text`                            | `truncate` または `wrap` —— 箱に入りきらないテキストの扱い          | `truncate`                 |
| `left-title`, `left-subtitle`           | テキスト —— 左の欄の 2 つの見出し                                   | `Procedure`・`Description` |
| `right-title`, `right-subtitle`         | テキスト —— 右の欄の 2 つの見出し                                   | `Remark`・空               |

オン・オフには `yes`/`on`/`1` と `no`/`off`/`0` も使えます。4 つの見出しは `/page/` にも書けますが、両方にある場合は `/option/` が勝ちます。

### `/role/`・`/block/`・`/prop/`

定義はどれも `<id>` を 1 行で書き、その下にプロパティを並べる形です。id は大文字小文字を区別し、`/line/` から参照されます。

| セクション | 定義するもの                 | キー                                                                                                                     |
| ---------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `/role/`   | スイムレーン 1 本            | `label`・`text-color`・`background-color`・`icon`                                                                        |
| `/block/`  | 再利用するステップのスタイル | `label`・`background-color`・`text-color`・`border-color`・`shape`・`icon`                                               |
| `/prop/`   | 脇に付く付箋                 | `label`・`side`（`left`/`right`）・`background-color`・`border-color`・`text-color`・`title`（別名 `hint`）・`max-chars` |

`shape` は `rounded`・`rect`・`note`・`hex`・`if`・`subroutine`・`ellipse`・`cloud` のいずれかです。`icon` の値が `#` で始まるときはアイコン名（`icon: #user;`）、それ以外は絵文字や文字がそのまま表示されます。ここにないキーもファイルには残り、描画されないだけです。`/line/` から参照されたのに定義がないロール・ブロック・付箋は自動的に作られます。

```
@kai-swimlane

/title/
定義の例

/role/
<sales>
label: 営業;
text-color: #1f2937;
background-color: #e0f2fe;
icon: #user;

/block/
<gateway>
label: 判断;
background-color: #ffe0b3;
border-color: #f59e0b;
shape: hex;

/prop/
<RQ>
label: 申請書;
side: right;
max-chars: 12;

/line/
[sales: 見積を作成する] <gateway>
props: RQ;

@end
```

### ステップ

| 構文         | 意味                                                 | 例                        |
| ------------ | ---------------------------------------------------- | ------------------------- |
| ステップ     | `sales` レーンの箱 1 つ                              | `[sales: 見積を作成する]` |
| スタイル参照 | `/block/` のスタイルを適用する。行の末尾にのみ書ける | `[sales: 見積] <gateway>` |
| 空のステップ | 何も入らない 1 行。番号も振られない                  | `:`                       |

ロール id に使えるのは英数字・`_`・`-` です。テキストにはコロンを含め何でも書けます。

### ステップのプロパティ

対象のステップの下に 1 行ずつ書きます。

| 構文           | 意味                                                                               | 例                               |
| -------------- | ---------------------------------------------------------------------------------- | -------------------------------- |
| `id:`          | 合流先として指せるように名前を付ける                                               | `id: closed;`                    |
| `label:`       | 左の欄に出る見出し（箱の中のテキストは変わらない）                                 | `label: 起案;`                   |
| `desc:`        | 説明欄                                                                             | `desc: 顧客要件を確認する;`      |
| `remark:`      | 備考欄                                                                             | `remark: 100 万円超は本部承認;`  |
| `remark-desc:` | `remark:` に段落を 1 つ追加する                                                    | `remark-desc: 上長が承認する。;` |
| `skip;`        | このステップを採番から外す                                                         | `skip;`                          |
| `level:`       | 採番上の深さ。`1`〜`9`                                                             | `level: 2;`                      |
| `link:`        | 別のフローを開く。このファイルからの相対パス、または `/` で図のルートから          | `link: ../ops/pick.md;`          |
| `props:`       | このステップに付ける付箋                                                           | `props: RQ, LG;`                 |
| `arrow:`       | このステップから出る線の種類：`solid`・`dashed`・`dotted`・`long-dash`・`dash-dot` | `arrow: dashed;`                 |

番号はレーンを持ち `skip;` の付いていないステップに順に振られます。`level:` はそれを入れ子にします。レベル 1 は 1, 2, 3 と数え、2 の後のレベル 2 は 2-1、次が 2-2、その後のレベル 3 は 2-2-1 になります。

長い `desc:` や `remark:` は複数行で書けます。

````
@kai-swimlane

/title/
長い値

/line/
[sales: 見積を作成する]
desc: ```
顧客要件を確認し、
見積を作成する。
```;

@end
````

### フロー

| 構文             | 意味                                                              | 例                                      |
| ---------------- | ----------------------------------------------------------------- | --------------------------------------- |
| `if … is … than` | 分岐の開始。2 つ目のかっこは最初のケースのラベル。`#color` は任意 | `if (承認する？) is (はい) than #green` |
| `else-if … than` | 名前付きの別ケース                                                | `else-if (修正が必要) than #orange`     |
| `else`           | 残りのケース                                                      | `else`                                  |
| `end-if`         | 分岐を閉じる                                                      | `end-if`                                |
| `fork`           | 並行する経路の開始                                                | `fork #purple`                          |
| `and`            | 次の並行経路                                                      | `and`                                   |
| `end-fork`       | 並行経路を合流させる                                              | `end-fork`                              |
| `section (名前)` | ステップをラベル付きの枠で囲む。フロー自体は変わらない            | `section (見積) #gray`                  |
| `end-section`    | 枠を閉じる                                                        | `end-section`                           |
| `branch (名前)`  | 脇道。先頭はつながらず、末尾が閉じた後の流れに合流する            | `branch (監査) #blue`                   |
| `end-branch`     | 脇道を閉じる                                                      | `end-branch`                            |

色名は `blue`・`green`・`red`・`orange`・`purple`・`gray`・`black`・`pink`・`teal`・`yellow` の 10 種類です。

### ジャンプと着地点

| 構文            | 意味                                                            | 例               |
| --------------- | --------------------------------------------------------------- | ---------------- |
| `[merge]`       | 本流の着地点                                                    | `[merge]`        |
| `[merge: name]` | 名前付きの着地点                                                | `[merge: join]`  |
| `merge;`        | ケースの中から、この `if` の後の最初の着地点へ進む              | `merge;`         |
| `merge: name;`  | ケースの中から、その `id:` のステップまたは名前付き着地点へ進む | `merge: closed;` |
| `[loop]`        | ケースの中から、質問へ戻る                                      | `[loop]`         |

```
@kai-swimlane

/title/
ジャンプ

/role/
<sales>
label: 営業;

/line/
if (承認する？) is (はい) than
[sales: 出荷する]
merge;

else-if (修正が必要) than
[sales: 見積を修正する]
[loop]

else
[sales: 却下を連絡する]
merge: closed;

end-if

[merge: join]

[sales: 案件を終了する]
id: closed;

@end
```

### 古い表記

以下も引き続き読み込めますが、フォーマットまたは保存のときに書き換わります。`endif` → `end-if`、`endfork` → `end-fork`、`elseif` → `else-if`、`section-start (n)` → `section (n)`、`start-point` → `section`、`end-point` → `end-section`、`***` のコメント → `//` のコメント。

### バージョン 2 で変わるところ

目に見えて変わるのは次の点だけです。`if (…) is (…) than` と `else-if` の代わりに `if [lane] (承認する？)` と `case (はい)`、`else` の代わりに空の `case ()`、`merge;`・`merge: id;`・`[loop]` の代わりに `goto`・`goto @id`・`loop`・`loop @id`、`[merge]` の代わりに `merge`・`merge @name`、`:` の代わりに `[]`、`id:`・`props:`・`arrow:` の行の代わりに接尾辞の `@id`・`+prop`・`~>`。さらにバージョン 1 に相当機能のない `@lang`・`@use`・`/meta/`・`phase`・ノート・`=> リンク` が加わります。それ以外——セクション構成、`/option/`、各種定義、`[role: text]`、`desc:`、`remark:`、`skip;`、`level:`——はどちらも同じです。

## ビジュアルモードでできること・できないこと

テキストモードでは上記のすべてを書けます。ビジュアルモードはその大部分をカバーし、編集できないものも、下の表に別途書いていない限り、ビジュアルモードで保存しても**そのまま保持**されます。

| 機能                                                                                                                                                                    | ビジュアルモード                       | 補足                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| タイトル、ページの説明、ヘッダー・フッターの各枠                                                                                                                        | 編集できる                             | **設定**の中。対応する `show-…` がオフの間はその枠自体が表示されない                                         |
| 欄見出し                                                                                                                                                                | 編集できる                             | 左の 2 つは左の欄がオフの間、右の 2 つは右の欄がオフの間は表示されない                                       |
| `show-left-gutter`・`show-right-gutter`・`show-header`・`show-footer`・`show-description`・`show-step-block-captions`・`merge-at-previous-block`・`branch-color-arrows` | 編集できる                             | **設定**のチェックボックス                                                                                   |
| `show-gateway-icons`・`block-margin`・`block-text`                                                                                                                      | **テキストモードのみ**                 | 対応する操作がまだない。値は保持される                                                                       |
| ロール・ブロック・付箋の定義                                                                                                                                            | 編集できる                             | すべてのプロパティと、追加・削除                                                                             |
| 定義の `<id>` の変更                                                                                                                                                    | **テキストモードのみ**                 | id は表示されるが編集できない                                                                                |
| レーンの並び順                                                                                                                                                          | **テキストモードのみ**                 | 定義した順に並ぶ                                                                                             |
| ステップの追加・編集・削除・並べ替え                                                                                                                                    | 編集できる                             | 上下移動と**移動先**は同じ分岐の中に限られる。ドラッグでは分岐をまたげるが、ファイルが壊れる移動は拒否される |
| ステップの `<block>`                                                                                                                                                    | 編集できる                             | 見た目で選べる                                                                                               |
| `id:`・`label:`・`desc:`・`remark:`・`props:`・`arrow:`                                                                                                                 | 編集できる                             | **詳細オプション**の中                                                                                       |
| `level:`                                                                                                                                                                | 対応                                   | 採番の階層 1〜9                                                                                              |
| `link:`                                                                                                                                                                 | 対応                                   | 「別のフローへリンク」でファイルを選ぶ。ブロックの ↗ をプレビューでクリックすると開く                        |
| `skip;`                                                                                                                                                                 | **テキストモードのみ**                 | 保存しても保持される                                                                                         |
| `remark-desc:`                                                                                                                                                          | **テキストモードのみ**、かつ書き換わる | 保存すると `remark:` 1 つにまとめられる。文章は残るが 2 行の形は残らない                                     |
| 空の `:` 行                                                                                                                                                             | 表示・削除のみ                         | ビジュアルモードでは作成も編集もできない                                                                     |
| `if`・`else-if`・`else`、条件、ケース名、色                                                                                                                             | 編集できる                             | 色は色名ではなく見本から選ぶ                                                                                 |
| `fork`・`and`                                                                                                                                                           | 挿入と色の変更                         | バージョン 1 の並行経路にはラベルがないため、それ以外に編集する項目がない                                    |
| `section`・`branch` の名前と色                                                                                                                                          | 編集できる                             | 一方から他方へ変換する操作はない                                                                             |
| `[loop]`                                                                                                                                                                | 挿入のみ                               | 設定項目はない                                                                                               |
| `merge;`・`merge: id;`・`[merge]`・`[merge: name]`                                                                                                                      | 編集できる                             | 行き先は既存の id から選ぶドロップダウン                                                                     |
| コメント                                                                                                                                                                | **テキストモードのみ**、かつ壊れやすい | 保存では保持されるが、ビジュアルモードのどこにも表示されず、ステップを削除するとそれに付いたコメントも消える |
| `/option/` の未知のキー                                                                                                                                                 | **消える**                             | エラーとして報告され、ビジュアルモードで保存すると行ごと削除される                                           |
| バージョン 2 の言語ごとの値                                                                                                                                             | **テキストモードのみ**                 | ビジュアルモードで編集すると先頭の言語だけが変わり、他の言語はそのまま残る                                   |
| バージョン 2 の `@use`・`=> リンク`                                                                                                                                     | **テキストモードのみ**                 | 保存しても保持される                                                                                         |
| バージョン 2 の `phase`                                                                                                                                                 | 一部のみ                               | グループとして表示され名前と色は編集できるが、新規作成できるのは `section` と `branch` だけ                  |

ファイルにエラーがあるときロックされるのは、そのエラーに対応する行だけで、ほかは編集できます。`/option/`・`/role/`・`/block/`・`/prop/`・`/page/`・`/title/` のエラーはどの行にも対応しないためどこもロックしません——そうしたエラーはテキストモードで直してください。
