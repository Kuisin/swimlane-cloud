# Public sharing

Sometimes the person who needs to see a diagram doesn't have — and doesn't
need — a Swimlane Cloud account. **Public sharing** creates a link anyone
can open, no sign-in required.

## Creating a link

From a published version, share a single diagram or a whole folder of
them. Each link points at that exact, immutable snapshot — if the diagram
changes later on `main`, the link keeps showing what it showed when you
created it, not whatever is current.

## What the other person sees

A clean, read-only page: the diagram, its title, and (for a folder link) a
simple index of everything inside it. There's no editor, no account
prompt, and no way to see anything in the repository beyond what the link
was scoped to share.

## Diagram-only links

If you'd rather not even reveal the underlying diagram source, a link can
be restricted to showing only the rendered picture — the person opening it
never receives the diagram's text at all.

## Revoking a link

Links can be turned off at any time from the same place you created them.
Once revoked, the link stops working immediately.
